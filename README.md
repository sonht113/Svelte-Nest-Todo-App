### Features

- ⚡ [Svelte](https://svelte.dev/)
- ⚡ [NestJS](https://docs.nestjs.com/)
- 🔥 Type checking [TypeScript](https://www.typescriptlang.org)
- 💎 Integrate with [Tailwind CSS](https://tailwindcss.com)
- 📏 Linter with [ESLint](https://eslint.org)
- 💖 Code Formatter with [Prettier](https://prettier.io)
- 🗂 VSCode configuration: Debug, Settings, Tasks and extension for PostCSS, ESLint, Prettier, TypeScript, Jest

```shell
git clone https://github.com/sonht113/Svelte-Nest-Todo-App.git
cd Svelte-Nest-Todo-App

--- TERMINAL FOR SERVER ---
cd server
npm install
>>> Add file .env >>> Add mongo_db url to MONGO_URL in .env (You can copy from .env.example)
npm run start:dev

--- TERMINAL FOR WEB ---
cd web
npm install
>>> Add file .env >>> Copy file .env.example to file .env
npm run dev
```
